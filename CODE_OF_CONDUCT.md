# Code of conduct

We want Steward's issues, reviews and discussions to be useful and welcoming.
Treat contributors respectfully regardless of experience, identity or background.

- Give specific, constructive feedback about the work.
- Assume good faith, listen to corrections and respect differing constraints.
- Do not harass, threaten, discriminate, publish private information or use sexual
  attention, insults or spam to disrupt participation.
- Do not publish credentials, private conversations or real user data as examples.

Maintainers may edit or remove inappropriate content, lock discussions or restrict
participation when needed, using proportionate action. Apply these standards to
maintainers as well as contributors. For abuse or private-information exposure,
use GitHub's **Report content** / **Report abuse** controls without repeating
sensitive details publicly. Vulnerabilities follow [SECURITY.md](SECURITY.md).

This policy applies to project spaces and public representation of the project.
It does not promise continuous moderation or a particular response time.
