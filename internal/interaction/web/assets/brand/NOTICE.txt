# Collie artwork

The Collie border collie holding a tennis ball was generated for this project
with OpenAI image generation on 2026-10-29 and selected by the project owner.
The supplied PNG is used unchanged for the welcome illustration, brand mark,
agent avatar and favicon. Browser CSS controls its displayed size.

Typography: Bricolage Grotesque and DM Sans, distributed unchanged under their
included SIL Open Font License notices. Font sources: google/fonts, ofl/
bricolagegrotesque and ofl/dmsans. No font service or image CDN is contacted.
