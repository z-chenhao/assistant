# Getting help

Start with the [installation guide](docs/features/installation.md),
[feature documentation](docs/feature-map.md) and
[operations guide](docs/features/operations.md).

Use [GitHub Issues](https://github.com/z-chenhao/steward/issues) for reproducible
bugs, feature proposals and usage questions. Search existing issues first and
include your revision, operating system, tool versions, exact command and a
minimal reproduction. `steward doctor` is read-only; `steward status` may open
or migrate state. Share only sanitized output and disposable fixture data.

For suspected vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of
posting an exploit, credentials, authentication URLs or private application data.
Community support has no guaranteed response time or service-level agreement.
