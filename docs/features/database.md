## 需求与验收

<a id="f-033"></a>

### F-033 · Web Database 检查入口

**需求**：后续可检查执行、对话、记忆和文件元数据，理解数据关系。

**当前实现**：当前存在各领域 SQLite 与控制命令；Web 没有通用数据库检查页。

**边界与剩余工作**：先确定允许的数据、脱敏/解密权限、分页与只读查询范围；读写修复不属于本次方向。

**验收目标**：范围确认后验证分页浏览、关联跳转、权限和敏感内容控制，不改变执行或领域状态。

## 如何使用

当前使用领域控制命令和诊断入口；没有 Database Tab。

未来入口位于 Developer。首版建议只读展示允许的表/投影，具体页面、查询能力与密文处理需在实施前明确；不要依赖假设中的任意 SQL 控制台。
