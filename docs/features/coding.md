# 受控代码工作与开发交付

读取和修改受控仓库，并逐步形成完整开发交付能力。

[需求主索引](../feature-map.md) · [技术方案](../designs/coding.md) · [测试方案](../test-plans/coding.md)

## 功能说明

用户能委派仓库理解、修改、验证，并获得可审查交付物。

本文描述用户行为和范围；逐项完成状态以主索引为准。当前能力依据代码静态盘点，配置可用性与真实服务/模型质量需分别验证。

## 需求与验收

<a id="f-026"></a>

### F-026 · 代码理解、修改与交付

**需求**：用户能委派仓库理解、修改、验证，并获得可审查交付物。

**当前实现**：有 read/search/status/diff、隔离固定 Go 测试及单个干净受跟踪文件的批准替换。

**边界与剩余工作**：缺少通用新建/删除、连续修改脏文件和提交交付链路；是否开放任意命令需单独决策。

**验收目标**：在一次多文件真实修改中完成理解、修改、测试和 diff 交付，同时保留用户变更和审批边界。

## 如何使用

操作员配置独占的可丢弃 Git checkout，包含 AGENTS.md，选择 audit 或 edit 模式。Agent 通过固定 workspace 工具读取、搜索、检查和验证。

当前 edit 要求已有文件、干净工作树以及匹配的内容/规则哈希；并非通用终端开发环境。完整开发交付仍按 F-026 补齐。
