## 需求与验收

<a id="f-032"></a>

### F-032 · Web Evals 入口

**需求**：后续可从 Developer 查看评测结果，并关联对应执行。

**当前实现**：当前无 Evals Tab；软件测试由 tests/ 管理，真实模型评测属于独立评测项目。

**边界与剩余工作**：先定义结果来源、导入/关联方式、指标和用户操作；本轮不新建评测框架或迁回历史 benchmark。

**验收目标**：范围确认后验证结果绑定产品版本、模型/配置与数据集版本，并能跳转相关执行；脚本回归不冒充模型质量。

## 如何使用

目前按 testing.md 运行软件回归，真实模型效果在独立评测项目中执行。Evals 页面尚不可用。

这里只登记未来入口，不提供尚不存在的页面或运行命令。首个迭代需先明确是展示外部结果、发起显式评测，还是两者都做。
