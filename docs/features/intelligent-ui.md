# 受控富 UI 交付

把语义结果呈现为文本、表格、附件、进度和确认组件。

[需求主索引](../feature-map.md) · [技术方案](../designs/intelligent-ui.md) · [测试方案](../test-plans/intelligent-ui.md)

## 功能说明

正常回复能产生适当的受控组件，失败可退回语义文本。

本文描述用户行为和范围；逐项完成状态以主索引为准。当前能力依据代码静态盘点，配置可用性与真实服务/模型质量需分别验证。

## 需求与验收

<a id="f-021"></a>

### F-021 · 富组件从生成到交互的闭环

**需求**：正常回复能产生适当的受控组件，失败可退回语义文本。

**当前实现**：组件 Schema 与渲染器已实现，审批有生成路径；普通 Compose 只产生 markdown/Artifact，form 当前为只读字段展示。

**边界与剩余工作**：补结构化结果到表格/进度/表单的生成映射；交互表单需定义提交与恢复语义。

**验收目标**：真实回复生成表格等组件，确认保持冻结审批；未知组件/坏数据 fallback；表单可交互时验证提交去重。

## 如何使用

现有回复显示文本和附件，待审批动作显示确认卡片。无需安装前端服务。

当前不能仅因 DataTable 或 form 渲染器存在，就期待普通对话自动生成表格或可提交表单。这部分按本需求继续实现。
