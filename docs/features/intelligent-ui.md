# Intelligent UI 交付

把语义结果呈现为文本、表格、附件、进度和确认组件。

[需求主索引](../feature-map.md) · [技术方案](../designs/intelligent-ui.md) · [测试方案](../test-plans/intelligent-ui.md)

## 功能说明

正常回复能产生适当的受控组件，失败可退回语义文本。

本文描述用户行为和范围；逐项完成状态以主索引为准。当前能力依据代码静态盘点，配置可用性与真实服务/模型质量需分别验证。

## 需求与验收

<a id="f-021"></a>

### F-021 · 富组件从生成到交互的闭环

**需求**：正常回复能产生适当的受控组件，失败可退回语义文本。

**当前实现**：Main 按需读取内建 `intelligent_ui` Skill，通过 Code Mode 调用 `builtin__intelligent_ui_show`。Web 支持 OpenIntelligentUI 原生表格等受控组件，以及 HTML/CSS/JavaScript 的隔离交互答案。工具产物与回复持久绑定，普通最终回答无需 JSON 围栏；文字替代覆盖其他渠道与渲染失败。

**边界**：Worker 不直接展示 UI。Widget 无 Host 权限；本地交互保持本地，提问先进入 Host 草稿，用户显式发送后才成为普通消息。原生表单只收集回答，所有外部动作仍需原审批。图表数据和完成状态必须有证据。

**验收目标**：实际 Main/Code Mode/UI 工具/Delivery 链路生成表格、交互计算器和表单；验证隔离、主题、展开、失败与无脚本降级、显式交互回传，以及重启后不重新执行。真实模型的选择与视觉质量另行评测。

## 如何使用

可请求 Ghost「按价格和适用场景比较这几个方案」或「先收集目的地和出发日期」。适合时，回复会显示表格、摘要或问答表单；简单回答仍可使用普通文字。无需安装前端服务。交互答案可展开或查看文字版本；Widget 的提问会先显示可编辑草稿，按 Send to Ghost 后发送。

填写表单后选择 **Send response / 发送回答**。所有字段均为必填文本，每项最多 4096 个 UTF-8 字节，整份回答（含问题和字段名称）最多 16 KiB。回答作为普通用户消息交给 Ghost；页面更新保留其他表单与对话输入框的草稿。无法确认发送时保留填写内容，先检查对话再重试；同一份已提交表单不能覆盖原回答，需要更正时发送一条普通消息。

刷新或重启后，已保存的表单显示原回答并停止重复提交。关闭 JavaScript 仍可填写和提交；失败页面保留可复制的回答草稿。未知或不受支持的内容显示文字替代。待审批动作继续显示独立确认卡片，表单不提供审批入口。
