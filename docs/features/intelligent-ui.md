# Intelligent UI 交付

以 OpenIntelligentUI 原生组件为基础，通过同一协议补充 HTML/SVG 图解、计算器、模拟和交互控件。

[需求主索引](../feature-map.md) · [技术方案](../designs/intelligent-ui.md) · [测试方案](../test-plans/intelligent-ui.md)

## 功能说明

正常回复能产生适当的受控组件，失败可退回语义文本。

本文描述用户行为和范围；逐项完成状态以主索引为准。当前能力依据代码静态盘点，配置可用性与真实服务/模型质量需分别验证。

## 需求与验收

<a id="f-021"></a>

### F-021 · 富组件从生成到交互的闭环

**需求**：正常回复能产生适当的受控组件，失败可退回语义文本。

**当前实现**：Main 按需读取内建 `intelligent_ui` Skill，经直接高频工具或 Code Mode 调用 `builtin__intelligent_ui_show`。原生能力复用 OpenIntelligentUI 的 Table、barChart、pieChart、plan_visualization 和 scheduleTime；扩展展示使用其 generateSandboxedUi 参数与完成态 open-generative-ui activity、共享主题/SVG/控件样式，以及 Websandbox 交互接口。旧 markdown/table/progress/form 与顶层 html/css/javascript 不再作为模型输入契约。工具产物绑定持久回复，UI 先于单独的文字气泡展示，文字替代覆盖非 Web 渠道和失败场景。

**边界**：Worker 不直接展示 UI。Widget 无 Host 权限；本地交互保持本地，提问先进入 Host 草稿，用户显式发送后才成为普通消息。原生表单只收集回答，所有外部动作仍需原审批。图表数据和完成状态必须有证据。

**验收目标**：实际 Main/Code Mode/UI 工具/Delivery 链路生成表格、交互计算器和表单；验证隔离、主题、展开、失败与无脚本降级、显式交互回传，以及重启后不重新执行。真实模型的选择与视觉质量另行评测。

## 如何使用

可请求 Ghost「按价格和适用场景比较这几个方案」或「先收集目的地和出发日期」。适合时，回复会显示表格、摘要或问答表单；简单回答仍可使用普通文字。无需安装前端服务。交互答案可展开；正常展示时不附加重复的文字版本入口，加载失败或无脚本时显示文字替代。Widget 的提问会先显示可编辑草稿，按 Send to Ghost 后发送。

原生表格可以排序、筛选和选择，图表支持分类联动及范围探索；新增折线图和散点图。控件状态、筛选、表单草稿及自定义展示状态自动保存，刷新与重启恢复；下一条用户输入会携带冻结的已保存组件状态。它可能属于旧话题，不表示当前打开的页面或本次请求的主题，只在与用户请求相关时作为证据使用。

表单支持文字、数字、日期、邮箱、单选、多选和布尔字段，按字段约束验证。发送后成为普通用户消息，已接纳的回答不能被另一份回答覆盖；无脚本页面提供原生表单。未确认发送保留答案并沿用原身份重试。所有外部动作仍走原审批。

卡片支持横向轮播和选择，图像使用授权附件。操作菜单按组件提供 CSV、SVG、PNG 和 HTML 快照导出，以及展开、弹窗和悬浮视图；切换模式保留交互状态。界面只展示内容、操作与必要状态，不添加功能介绍文案。

已声明的工具动作由宿主按钮发起，Main 通过现有执行链处理，结果按输入与调用记录关联回传。生成式展示只能提出已声明动作，不能任意调用工具或批准操作。模型没有执行所提工具时显示失败，不能把普通文字答复当成成功结果。

## 原生交互与扩展

表格保留来源字段，柱状图和饼图支持上游导出操作；方案卡描述展示方案。时间选择器必须给出实际候选时间，用户选择或拒绝经既有消息接纳链路持久化，刷新与重启可还原，不宣称已创建日历会议。

HTML/SVG 扩展可以提供流程图、架构图、图表、计算器和教学模拟。组件参数与共享 SVG/控件基础来自上游，字体、色彩、字号、边框和间距适配 Steward 的设计语言；通过局部控件更新结果，不把答案做成嵌入式网站。沙箱按内容自适应高度，复杂内容可展开；完整文字替代保留在交付数据中，正常交互界面不重复展示。按钮组保留明确间距，窄屏自动换行。

协议兼容范围是组件名称/参数、generateSandboxedUi 六字段、完成态 activity 和 Websandbox.connection.remote 接口。Steward 使用自己的持久执行和传输；Web 支持参数生成过程的受控流式预览：直接调用逐步显示完整表格行、图表点和 HTML/SVG 内容；Code Mode 在 UI 调用实际暂存后立即显示，无需等待最后的文字回复。预览标注生成中，所有控件禁用且脚本不执行；正式回复交付后才启用既有交互。取消、失败或断线会撤下临时视图，历史仍只保存正式结果。外部 CDN/库不属于本地沙箱承诺；选项、滑块与模拟默认本地运行。

富组件与 Settings、Task、Dev 使用同一基础控件体系。组件内部边界、间距、悬停、焦点和选中效果统一；字体字号、页面布局及消息气泡沿用 Steward。表格数字列对齐，图表提示与图例按主题展示，表单、卡片和时间候选共用控件外观；不增加介绍性文案。

超宽图和表格可在组件内左右滑动，滚动条默认隐藏，支持触控板、触摸与键盘，聊天页面不会被内容撑宽。放大、弹窗和固定视图仍保留同一内容实例与输入。

静态 HTML/SVG 无需脚本时使用 `jsFunctions: ""`、`jsExpressions: []`。工具也兼容把空字符串 `jsExpressions: ""` 规范化为数组后保存，避免有效静态展示在预览完成后因该空值丢失；非空字符串仍拒绝；Skill 明确各空字段类型。
