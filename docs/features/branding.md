# Collie 品牌与个人工作空间

把一项任务交给私人助手，就像把网球扔给边牧，期待它带着结果回来。

[主索引](../feature-map.md) · [技术方案](../designs/branding.md) · [测试方案](../test-plans/branding.md)

## 功能说明

Collie 是拥有对话、工具、记忆与委派任务的私人助手。边牧咬网球的原图由项目所有者选定；它用于首页、导航、头像和 favicon。暖白、墨黑与网球黄绿构成统一界面，Lora 用于欢迎标题，DM Sans 用于品牌字标、操作和阅读；中英文正文使用明确的系统中文字体回退。低对比侧栏、紧凑的欢迎区与清晰的发送箭头将视觉重心留在输入框。字体与图像本地嵌入，无远程资源请求。

## 需求与验收

<a id="f-041"></a>

### F-041：品牌、身份与工作空间

- 首页以边牧、提问标题与输入框引导用户交付工作；输入、附件、审批、恢复继续使用真实产品链路。
- Conversation、Tasks、Settings、Developer 共用导航、字体、颜色、控件与反馈。未配置模型时优先显示设置入口，不暗示已就绪。
- Collie 是唯一项目名。Go 模块、CLI、配置环境变量、数据根、事件命名空间、Runtime 标识和备份格式均采用新名，无旧名别名或迁移层。
- 提交期间有轻量反馈；失败保留草稿与附件，不自动重发。不以动画或品牌文案伪造任务完成。减少动态效果偏好会关闭动画。
- Main/Worker 的职责、四种 Task 状态、审批与 Durable Replay 机制保持有效；本轮不增加 Agent 工具或新执行管线。

## 如何使用

构建后运行 `bin/collie start`，或安装后运行 `collie`。默认数据根为 `~/.local/share/collie`；显式配置使用 `COLLIE_DATA_ROOT` 等 `COLLIE_*` 变量。完整操作见[安装](installation.md)。Web 首次连接模型后，在首页输入请求并发送；Tasks 查看实际任务，Settings 管理模型与通知，Developer 检查执行与上下文。

本次为无使用者阶段的身份重置，不读取旧身份的数据、凭据命名空间、备份或运行标识。已有文件不会被安装器主动删除。新 Collie 安装之间仍提供备份与恢复。
