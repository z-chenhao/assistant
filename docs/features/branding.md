# Steward 品牌与个人工作空间

Your personal AI steward.

[主索引](../feature-map.md) · [技术方案](../designs/branding.md) · [测试方案](../test-plans/branding.md)

## 功能说明

Steward 是拥有对话、工具、记忆与委派任务的私人助手。产品名为 Steward，当前 Agent 名为 Ghost。字标使用 Michroma，形象为黑白小幽灵。正式 Web 使用非纯黑纯白的单色界面，Chat 发送按钮以橙色作为局部例外，英文界面为 Inter，回复正文为 Source Serif 4，中文优先 PingFang SC、回退自托管思源黑体；代码为 JetBrains Mono。图片与字体全部同源嵌入。

## 需求与验收

<a id="f-041"></a>

### F-041：品牌、身份与工作空间

- 单个 256px 侧栏；首页接续真实持续对话，采用居中正文、无卡片回复、浅灰用户气泡与多行输入。Computer/Worker 详情按需查看实时画面和执行历史；成果仍归实际任务及其交付消息。
- Conversation、Tasks、Settings & capabilities、Developer 共用配色和控件。公共控件复用与选项状态测试属于现有 CI 必过检查，Task 计划页沿用真实浏览器验证保存与回退。下拉选择与普通布尔开关在跨页使用同一套外观与交互，页面各自保留原有保存、筛选或即时应用行为。操作页采用共享字号、对齐的字段和按钮，以及单一可见标题；760px 及以下的普通输入使用 16px，按钮、选择器和折叠入口保留至少 44px 的触控高度。模型选用前常驻显示提供方同意说明，Trace 树逐项显示可读状态文字。模型未就绪时显示配置入口并禁用发送。
- 浅色用深色幽灵，深色用浅色幽灵；可暂停动效，尊重 reduced-motion、页面可见性和离屏状态。悬停问候时头像尺寸和点击区域保持稳定。动画只表达角色反馈，不伪造任务状态。
- 实际发送、附件、审批、冻结哈希、任务接续、分页与实时更新维持既有执行链路。未确认发送保留草稿与附件，不自动重发。
- 品牌贯穿 Web、终端、授权页、安装器与打包说明。命令为 `steward`，环境变量使用 `STEWARD_*`，默认数据根为 `~/.local/share/steward`，模块为 `github.com/z-chenhao/assistant`。不提供其他品牌的命令、路径、协议或配置别名。

当前 README 与 favicon 使用与 Web 正式头像同源的静态首帧；生成方式和资源边界见技术方案。

## 如何使用

构建后运行 `bin/steward web serve`（需 Web 配置）或正常启动应用。默认数据根为 `~/.local/share/steward`。在首页对话并审阅具体审批；Tasks 可查看摘要、历史、关联消息与成果，Settings 管理模型、账户、通知和能力，Developer 查看真实执行与冻结上下文。Chat 右上角 Computer/Worker 展开即时查询的只读详情；已完成的 Worker 不等同于最终用户交付或文件成果。

外观、侧栏折叠及头像动效偏好保存在当前浏览器；它们不更改 Agent 执行策略。没有新增多会话、独立记忆浏览器或虚构的文件库。完整操作见[安装](installation.md)及[Web 功能](channels.md)。

### 界面语言

默认界面为英文，不根据浏览器语言自动切换。进入 Settings & capabilities → Preferences → Language，确认简体中文后自动保存并重新加载界面；中文路径为“设置与能力 → 偏好设置 → 语言”。语言名称和问号在设置组左侧，当前值和下拉箭头在右侧，列表仅显示 English、简体中文及选中标记；正常界面无 Save 或自动保存说明。Preferences 标签提示当前位置，正文不重复显示大标题。窄屏和放大时允许有序换行。

方向键只浏览，Enter／Space 或点击确认不同值才提交；Escape、Tab、外部点击取消未确认浏览。保存期间阻止重复操作，成功后读回浏览器偏好再确认；明确拒绝保留此前值并提供重试或检查入口。网络结果不明时显示“保存结果未确认”和“刷新核对”，先刷新读取实际偏好，不自动重发。返回页面时重新读取当前值。

将鼠标移到语言旁的问号或用 Tab 聚焦，可查看语言偏好的说明；提示可移入阅读，Escape 关闭并保留焦点。点击或触摸问号可开关，点击外部也会关闭。未启用 JavaScript 或语言增强初始化失败时，保留原生选择器与小型保存按钮；未启用脚本的问号使用原生展开说明。脚本可用但不支持浮层时，原生选择器仍自动保存。偏好仅对当前浏览器有效，刷新和跨页面导航后保留，登录页及实时片段也按该偏好呈现。仅翻译产品界面、状态和诊断说明；对话内容、任务标题与摘要、文件、模型名、冻结参数及原始执行证据保留原文。


Settings 保留一级侧栏并在相邻二级栏展开分类。侧栏底部仅保留 Settings；外观与头像动效统一在 Preferences 调整，保存于当前浏览器并遵循系统减少动态效果偏好。公共规则见 [design.md](../../design.md)。

同级设置页均展示页面标题；模型列表按实际内容宽度换行。侧栏折叠跨模块、分类和刷新保留，首次样式前读取本地偏好；手机端慢脚本加载不先展开整块导航。偏好设置为脚本专属项预留位置，脚本下载失败仍可使用原生导航与语言保存。通知渠道仍显式保存，编辑后显示未保存并撤下旧保存提示。
