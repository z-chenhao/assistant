# GC-05 career verification

`scripts/verify_gc05.py` drives the original career conversation through the
production CLI/TUI, Main/Context Builder, Memory/Curator, read-only MCP,
restricted QuickJS, Artifact and Delivery boundaries. Explicit scripted profiles
prove transport, persistence and recovery. They do not prove understanding,
career advice, research quality or suitability. `semantic_score=null`,
`eligible_for_grading=false`, `release_ready=false`. Real model/opportunity-source
and current L2 evidence remain with
[ERII-223](https://multica.ai/erii-studio/issues/01a16936-335f-72a4-a7f4-618823a87151).

```sh
make build
python3 scripts/verify_gc05.py --binary bin/erii --evidence evidence/gc05.json
python3 scripts/verify_gc05.py --binary bin/erii --evidence evidence/gc05.json --validate
python3 scripts/prepare_release_eval.py --input evidence/gc05.json --evidence evidence/gc05-preview.json
python3 -m unittest discover -s scripts -p 'test_gc05.py'
```

The existing `security` suite owns this gate. All six locked `m6-v1`
wording/noise/order variants run five serial repetitions each. `--variant-jobs`
bounds independent variants (1, 2 or 4). No repetition, Golden input, scoring
or protection assertion changes. The additional lock binds the original manifest
SHA256 `0120228762abfe54dd477bc27853b3b45338d0ea5f19363a3d3b742224f5c556`
and exactly its 19 GC-05 blocks. Supplemental synthetic direction-change,
project/privacy and Forget probes are separately locked; they never replace
original events or imply additional facts about either company.

`--validate` independently recomputes every assertion across 30 ordered receipts.
It binds authoritative persisted Code Mode returns to convenience summaries,
source/Memory Tool results, saved/published Artifact references, reopened bytes,
completed model output and visible delivery. It rejects missing/duplicate/drifted
rows, locks, identities and cleanup, and runs 20 corruption probes against a
passing native receipt. Probes include synchronized forged returns, stale
profiles, invented facts/metrics, privacy leaks, false live research, missing
checks, comparable equity, fabricated resignation, wrong references, broken
lineage, false restart, duplicate attempts, external actions, revived old owner,
deleted Recall and replay drift. Consistency receipts are not cryptographic
execution attestation; clean exact-SHA independent review is still required.

The public `gc05_native_manifest` is small. Full native bytes remain beside it
under `.gc05-native/`, bound by relative path, size and SHA256. The strict reader
rejects unsafe paths, symlinks, missing bytes and summary drift. CI's existing
uploader excludes hidden files; Builder retains raw bytes and the binary under
the durable local evidence root for same-host review. Missing bytes are
inconclusive. Judge preparation emits no packets or scores from this script.
The existing `unscripted_cases.py freeze --case GC-05` sends only original user
context/events through the production Pi Bridge and an operator-prepared profile.
Its historical-recall/opportunity-source adapter is incomplete and ineligible for
grading; see [unscripted operations](guides/unscripted-evals.md).
