# GC-06 learning verification

`scripts/verify_gc06.py` drives the frozen learning conversation through the
production CLI/TUI, Main/Context Builder, Memory/Curator, read-only MCP,
restricted QuickJS, Artifact and Delivery. Supplemental probes cover an unrelated
Task and an explicitly requested Automation/Root. Scripted replies prove
transport and mechanical constraints. Objective field completion proves its
declared rubric; it does not measure English proficiency or teaching quality.
`semantic_score=null`, `eligible_for_grading=false`, `release_ready=false`.
Real model assessment, a full unscripted learning adapter and current L2 remain
with [ERII-223](https://multica.ai/erii-studio/issues/01a16936-335f-72a4-a7f4-618823a87151).

```sh
make build
python3 scripts/verify_gc06.py --binary bin/erii --evidence evidence/gc06.json
python3 scripts/verify_gc06.py --binary bin/erii --evidence evidence/gc06.json --validate
python3 scripts/prepare_release_eval.py --input evidence/gc06.json --evidence evidence/gc06-preview.json
python3 -m unittest discover -s scripts -p 'test_gc06.py'
```

The `security` verification shard owns the gate. Six unchanged locked `m6-v1`
wording/noise/order variants each run five serial repetitions. Independent
variants use `--variant-jobs` (1, 2 or 4). The additional lock binds the original
manifest SHA256
`0120228762abfe54dd477bc27853b3b45338d0ea5f19363a3d3b742224f5c556`
and exactly its 19 GC-06 source blocks. Supplemental assessment, private raw
text, pause and explicit reminder data never replace the original events.

`--validate` recomputes every assertion across 30 ordered receipts. Persisted Code
Mode returns bind convenience copies to native Tool results, current Memory,
saved/published references, reopened bytes and visible delivery. Corruption probes
reject changed inputs/languages, fabricated scores, stale progress, permanent
deficits, refund claims, missing corrections, forged Artifact references,
lineage/restart/cleanup drift, unsolicited reminders, wrong schedule/timezone,
private recall, cancelled admission, revived owners and duplicate effects.
Consistency receipts do not attest execution cryptographically; independent
review still uses a clean exact-SHA checkout.

The small `gc06_native_manifest` refers to full bytes under `.gc06-native/` by
relative path, size and SHA256. Strict readers reject path traversal, symlinks,
missing bytes, duplicate JSON keys, non-finite numbers and summary drift. CI's
existing uploader excludes hidden bytes; retain those and the binary in the
durable local evidence root for review. Missing raw evidence is inconclusive.
`prepare_release_eval.py` emits no Judge packets or scores from this script.
The maintained `unscripted_cases.py freeze --case GC-06` sends only original user
context/events through the production Pi Bridge and an operator-prepared profile.
Its durable learning/assessment/schedule adapter is incomplete and ineligible for
grading; see [unscripted operations](guides/unscripted-evals.md).

GC-06 is registered in the fixed `security` finance part alongside GC-03.
The three-part join requires all 24 logical invocations, including GC-04/GC-05
and every five-round protection series. This adds no job, lane, timeout or
runner resource; combined exact-SHA CI and independent acceptance remain required.
